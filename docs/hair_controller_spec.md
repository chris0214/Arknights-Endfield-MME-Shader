# EndfieldHair_controller_Range5.pmx 规格

`EndfieldHair_controller_Range5.pmx` 是唯一保留的头发运行时控制器。全局灯光、阴影和天气仍由
`Endfield_controller.pmx` 管理；正式头发入口只从本控制器读取头发参数。

- 所有 morph 名均为 ASCII，避免 MME/CP932 名称匹配失败。
- 所有滑块的中性值都是 `0`。不加载控制器时，画面与 C3 烘焙默认完全一致。
- `+` 与 `-` 是一对方向相反的控制，正常使用时不要同时拉高。

## 高光形状

| morph | 0 -> 1 的作用 |
|---|---|
| `高光強+` | 高光从烘焙强度提高到 2 倍 |
| `高光強-` | 高光从烘焙强度降到 0 |
| `高光上移` | KK 基础 Offset 增加 `0.25`，整条发带上移 |
| `高光下移` | KK 基础 Offset 减少 `0.25`，整条发带下移 |
| `上層比+` `上層比-` | 上层颜色分区坐标偏移 `+/-0.15` |
| `上層硬+` | 上沿裁切软度从 C3 的 `0.015` 收到 `0.001` |
| `上層硬-` | 上沿裁切软度放宽到 `0.1` |
| `下層柔+` | 下沿 Power 从 `0.75` 降到 `0.35`，尾部更柔 |
| `下層柔-` | 下沿 Power 提高到 `1.25`，尾部更短促 |
| `分層混+` | 上/中颜色过渡区变宽 |
| `分層混-` | 上/中颜色过渡区变窄 |

`高光上移/Down` 同时进入基础瓣和裁切瓣，因此只移动共同高度，不改变 `CutOffset=0.25`
建立的相对带宽与上沿方向。

C3 的 `LowerSoftness` 曾直接作用于对称 KK 基础瓣，因此会同时带动上下两边。C4 根据基础瓣与
裁切瓣的有符号相对位移自动识别下半瓣，只在远离上沿裁切中心的一侧执行 Power；模型左右侧或
叉乘手性变化时无需翻转固定符号。请使用文件名含 `LowerOneSided` 的 C4 测试该控制。

## 高光颜色

| morph | 0 -> 1 的作用 |
|---|---|
| `高光暖+` | 上层暖色混合从 `0.35` 提高到 `1.0` |
| `高光暖-` | 上层暖色混合从 `0.35` 降到 `0.0` |
| `中層飽和+` `中層飽和-` | 中层饱和度从 `1` 调到 `2` / `0` |
| `上層赤+/-` `上層緑+/-` `上層青+/-` | 上层各通道从参考值推向 `1` / `0` |
| `中層赤+/-` `中層緑+/-` `中層青+/-` | 中层各通道从参考值推向 `1` / `0` |

C3 的中性高光强度是 C2 的 `1.05` 倍。强度控制只乘高光贡献，不抬基础发色、阴影或 Rim。

## 基础发色与 Rim

| morph | 0 -> 1 的作用 |
|---|---|
| `基色赤+/-` `基色緑+/-` `基色青+/-` | 基础发色各通道乘子从 `1` 调到 `2` / `0` |
| `基色飽和+` `基色飽和-` | 基础发色饱和度从 `1` 调到 `2` / `0` |
| `基色亮度+` `基色亮度-` | 基础发色亮度从 `1` 调到 `2` / `0` |
| `基色曝光+` `基色曝光-` | 基础发色曝光 `+1 / -1 stop` |
| `辺光強+` `辺光強-` | 头发屏幕空间 Rim 强度从 `1` 调到 `5` / `0` |
| `辺光幅+` `辺光幅-` | 屏幕空间 Rim 偏移宽度从 `1x` 调到 `5x` / `0.2x` |
| `辺光硬+` `辺光硬-` | 遮罩对比度从 `1` 调到 `8` / `0.25`；正向更窄更硬，反向更宽更柔 |
| `辺光色切` | `0` 读取 PMX 材质 `EDGECOLOR.rgb`，`1` 使用手动 Rim RGB；中间值连续混合 |
| `HairRimR/G/B+/-` | 只在手动颜色模式中调整对应通道，范围 `0..1` |

基础发色调节在线性空间、AO/明暗平衡之后执行；Hair Rim 和高光随后独立相加，因此不会因为改
基础发色而改变发带遮罩或 Rim 宽度。

## 生成与校验

控制器由下列命令从现有全局控制器的有效 PMX 骨架生成，不会修改源文件：

```powershell
python tools\build_hair_controller.py
```

生成器会验证 PMX 结构、85 个 morph 的逐字名称和非空中性 Bone Morph，然后输出 SHA-256。

## 扩展形状与刘海投影参数

| morph | 0 -> 1 的作用 |
|---|---|
| `外層法線+` | 外层高光法线从 `25% HN.ba` 推到纯 `HN.ba` |
| `外層法線-` | 外层高光法线从 `25% HN.ba` 推到纯球形法线 |
| `高光横幅+/-` | 横向 NoV 覆盖扩大 / 收窄，不改变中心高度 |
| `高光縦厚+/-` | KK Range 降低 / 提高，即纵向变厚 / 变薄 |
| `鋸歯強+/-` | 提高 / 关闭 ST.r 对高光切线的位移强度 |
| `鋸歯密度+/-` | 提高 / 降低 ST 的 U 向重复频率，即齿形密度 |
| `頂光強+/-` | 顶光贡献提高一倍 / 关闭 |
| `頂光位置+/-` | 顶光覆盖向侧面扩张 / 向头顶收缩 |
| `暗線強+/-` | P.a 与 HairLine 漫反射暗线增强 / 关闭 |
| `暗線飽和+/-` | 暗线结果保留更多彩色 / 进一步去色 |
| `髪影左移/Right` | 在视空间水平微调真实刘海投脸阴影，不改变灯光跟随方向 |
| `髪影上移/Down` | 在视空间垂直微调真实刘海投脸阴影；当前偏低时使用 `髪影上移` |
| `髪影強+/-` | 阴影 Alpha 从中性提高 / 降低；`-` 满值时严格为 0 |
| `髪影亮+/-` | 只调整阴影 RGB 亮度，不改变 Alpha 或轮廓 |
| `FaceShadowR/G/B+/-` | 各通道从烘焙粉棕色推向 `1` / `0` |

样例模型的 ST 是沿 V 基本不变的纵向条纹，因此 C5 只暴露有实际信息的 U 频率；伪造一个
`JaggedFrequencyY` 不会产生可靠的新细节。

纯 `HN.ba` 只保证单张发片内部更顺。PMX 没有 Unity 原生切线，MME 的导数 TBN 会在断开的
刘海发片间跳变；因此默认继续使用 `75%` 球形法线加 `25% HN.ba`，而不是把纯 HN.ba
误当成全局更平滑。

## Range5 五倍范围控制器

正式 Shader 把 MMD 的 `0..1` 滑块映射到扩展范围。滑块为 `0` 时仍精确返回烘焙中性值。

扩展映射按参数语义分三类，不能把所有数值简单乘 5：

| 参数类型 | Range5 的 `0 -> 1` 映射 |
|---|---|
| 强度/乘子 `+` | 从中性 `1x` 线性提高到 `5x` |
| 强度/乘子 `-` | 从中性 `1x` 线性降低到 `0x` |
| XY 缩放、ST U 频率 `+` | 从 `1x` 提高到 `5x` |
| XY 缩放、ST U 频率 `-` | 从 `1x` 降低到 `1/5x`，不会变成零尺寸 |
| `高光上移/Down` | 位移行程从 `+/-0.25` 扩为 `+/-1.25` |
| `髪影左移/右移/上移/下移` | 各方向满值为 `0.125` 视空间单位；零值严格保持已验收位置 |
| `髪影強+/-` | 中性 `1x` 到 `5x` / `0x`；反向满值完全关闭投影 |
| `髪影亮+/-` | RGB 亮度从中性 `1x` 到 `5x` / `0x`，不改变 Alpha |
| `髪影赤/緑/青+/-` | 烘焙颜色各通道推向 `1` / `0`，始终钳制在合法范围 |
| 上/中高光 RGB、HN 混合、P.a/HairLine 强度和饱和度 | 继续限制在物理有效的 `0..1` |
| 基色 RGB/亮度、饱和度和辺光 `+` | 中性 `1x` 到 `5x`；对应 `-` 可降到 `0` |

具体地说，`高光強`、`辺光強`、`頂光強` 和 `鋸歯強` 的正向满值均为各自
烘焙值的 `5x`；`高光横幅/縦厚` 与 `鋸歯密度` 的正向满值为 `5x`，反向满值
为 `0.2x`。`頂光位置` 是法线覆盖阈值而非光能量，最终限制在 `-0.75..0.75`，避免
超出单位法线仍继续累加无效数值。高光 RGB 等颜色编辑仍是 `0..1`，不会产生负色或越界权重。

### 顶冠局部顶光

旧 C5A 严格保留文章的上向 Half-Lambert，垂直侧面在默认值下仍有非零贡献，因此视觉上会
像整头提亮。新 C5A2 改为世界向上法线锥形遮罩：默认在 `N.y=0.45` 开始，在 `N.y=0.70`
达到满强度，侧面和向下表面为零。遮罩以几何法线为主、混入 `25%` 细节法线，避免法线贴图
把顶冠区域切碎；它不读取 MMD 灯光方向。

- `頂光強+`：默认 `0.12` 的顶光贡献最高可到 `0.60`。
- `頂光強-`：可连续降到 `0`。
- `頂光位置+`：降低锥形阈值，向侧面扩张覆盖。
- `頂光位置-`：提高锥形阈值，只保留更靠近头顶的表面。

## 正式封版

`EndfieldHair_Final.fx` 是 A2 与 B2 的正式合并文件，使用
`EndfieldHair_controller_Range5.pmx`。其中原 60 个着色 morph 在正式 Hair 主体中保持有效：
Base RGB、饱和度、亮度和曝光在 VS 预计算后传给主 PS，HairRim 在独立 Rim PS 中读取，其余
高光、HN、XY/ST、顶光和暗线控制留在主 PS。追加的十四个 `FaceShadow` morph 只在启用动态
刘海投影 Pass 的入口中读取：四个位置项进入 Shadow VS，十个强度、亮度和 RGB 项进入 Shadow
PS；它们不会改变普通正式 Hair 的中性画面。

颜色链保留已验收的 Goo A/B 三层观感，并真正接回 RS：

```text
highlightColor = GooLayerColor + linear(RS(U,V)) * 0.28 * 0.35
U = saturate(dot(viewDirWS.xz, hairNormalWS.xz))
V = saturate(rawKkRange)
```

`0.28` 来自 MyZmd 的介电 `F0=0.04` 乘 LUT Gain `7`；`0.35` 是保留 Goo 主色的融合比例。
文章写法先投影到 cameraRight/cameraForward 再做二维点积；两向量构成世界 XZ 正交基，因此
它严格等价于 `dot(V.xz,N.xz)`，不是近似或改换算法。

屏幕空间 Rim 独立成同一 technique 的 `DrawHairRim` 加法 Pass。MME Script 显式按顺序执行
`DrawObject`、`DrawHairRim`；主 Pass 继续一次性在线性空间合成漫反射、顶光、暗线和 KK/RS，
避免为了预算拆开主体颜色。当前预算：主 PS `504/512`，主 VS `48`，Rim PS `146`，Rim VS
`16`；全部 pass 和 effect 均通过 FXC，正式 effect 另通过 `/Ges` 严格编译。

`辺光色切=0` 是正式默认：Shader 读取 PMX 材质面板中的描边 RGB，并从 sRGB 转到
线性光照空间。MMD 原生描边是否显示与该取色互不绑定，因此可以关闭原生描边而继续用同一
颜色驱动屏幕空间 Rim。`EDGECOLOR.a` 不参与 Rim 能量；强度由 `辺光強+/-` 独立控制。

上述结果完成工程封版。`DrawHairRim` 使用预算约束下的 `ONE/ONE` 加法 Pass，最终视觉验收仍需
在 MMD 中确认边缘光亮度、RS 色相以及转镜头和转灯光时的稳定性。
