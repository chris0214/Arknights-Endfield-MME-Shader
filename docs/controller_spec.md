# Endfield_controller.pmx 规格（M1 头发）

> 各部位 look-dev 参数已经拆到独立控制器。本控制器负责全局灯光、天气、通用明暗以及
> 所有主要角色材质共用的最终亮度和饱和度。

控制器是一个 PMX 模型，MME 通过 `CONTROLOBJECT` 语义按名字读取它的**表情槽（morph）滑块值 [0,1]**。
着色器里所有 `string name = "Endfield_controller.pmx"` 的引用都要求存在同名 PMX，且含以下 morph。
**若控制器缺失或缺某 morph，MME 返回 0**，着色器已设计为此时全部落在中性默认（无副作用），所以
先不做控制器也能出画，只是没有运行时滑块。

正式文件位于 `controller/Endfield_controller.pmx`。其可见网格是一个约 `0.001` MMD 单位的
透明单三角面，骨骼与表情仍按常规 PMX 保存。添加下列**表情（morph，类型随意，通常
用材质/组 morph 占位即可，只要名字对得上；滑块范围 0~1）**。名字必须**逐字节精确**（M1 全 ASCII，无需 CP932）。

## 光照
| morph 名 | 作用 | 默认档 |
|---|---|---|
| `CameraLight` | ≥0.5 时主光跟随相机偏航固定光 | 0 |
| `LightYaw+` `LightYaw-` `LightYaw++` `LightYaw--` | 相机光方位角微调（±90°，叠加±90°） | 0 |
| `LightPitch+` `LightPitch-` | 相机光仰角微调 | 0 |
| `灯光強+` `灯光強++` `灯光強-` | 主光强度（1→10 倍 / 归零） | 0 |
| `灯光赤+` `灯光緑+` `灯光青+` | 主光色相偏移 | 0 |
| `日光強+` `日光強-` | 晴/阴混合，`日光強-`→阴天(0)，默认晴天(1) | 0 |

## 明暗 / 阴影
| morph 名 | 作用 |
|---|---|
| `亮部+` `亮部++` `亮部-` | 亮部乘子 |
| `暗部+` `暗部++` `暗部-` | 暗部乘子 |
| `明暗線+` `明暗線-` | 亮区宽窄（rampNoL 偏移） |
| `陰影強+` `陰影強-` | Sigmoid 阴影阈值偏移 |
| `Self陰影強+` `Self陰影強++` `Self陰影強-` | ZMDshadow 自阴影强度 |

`Bright/Dark` 现在会分别作用于头发、面部、皮肤和衣服的亮/暗分支。

## 整体画面

| morph 名 | 作用 |
|---|---|
| `全局亮度+` `全局亮度++` `全局亮度-` | 所有主要角色材质的最终整体亮度，范围 `0..5x` |
| `全局飽和+` `全局飽和++` `全局飽和-` | 所有主要角色材质的最终整体饱和度，范围 `0..5x` |

整体控制在各部位 Shader 完成本地光照、高光和颜色处理之后执行，因此不会覆盖头发、面部、
皮肤或衣服控制器中的细节参数。所有滑块为 `0` 时保持原封版画面。

## 雨水

| morph 名 | 作用 |
|---|---|
| `雨量` | 全角色雨水总量；默认 `0` 完全干燥，`1` 为生产上限（当前相当于原验收效果的 150%） |
| `雨滴大小+` `雨滴大小-` | 调整全角色雨滴尺寸；端点范围扩大为约 3 倍放大 / 2.5 倍缩小 |
| `雨滴消散+` `雨滴消散-` | 调整雨滴消散速度；最快约 `0.065s`，最慢约 `2.6s`，中点仍为 `0.65s` |

雨水效果使用时再提高 `雨量`；控制器初始值保持 `0`，不会改变正常干燥材质。大小和消散滑块保持 `0` 时仍使用当前验收参数。

## 高光 / 边缘
| morph 名 | 作用 |
|---|---|
| `全局高光+` `全局高光++` `全局高光-` | Kajiya-Kay 高光强度（1→10 倍 / 归零） |
| `全局辺光+` `全局辺光-` | 轮廓光强度 |
| `髪高光上移` `髪高光下移` | 头发高光**上下位置**微调（在 .fx 里烘焙的 EF_VIEWDIR_Y_OFFSET 默认值基础上叠加 ±0.5） |

## 头发分域调色
| morph 名 | 作用 |
|---|---|
| `Hair全局飽和+` `Hair全局飽和-` | 头发饱和度 |
| `Hair全局亮度+` `Hair全局亮度-` | 头发亮度 |
| `髪曝光+` `髪曝光-` | 头发曝光（±stops） |

## 另需的外部对象
- **`ZMDshadow.x`**：正式投影、自阴影与深度后端（附件加载）。不要再同时加载旧 `HgShadow.x`。
- 后续里程碑（Face SDF）会再要一个头骨引用与发根中心骨；M1 头发不需要（`EF_FACE_CENTER` 用原点）。

> 说明：`tools/minimize_controller_geometry.py` 会保留表情名称、顺序和分类，将其载荷规范化为
> 不改变模型外观的骨骼 0 表情，并在不修改骨骼、显示枠和物理段的前提下，把五个控制器统一
> 重建为透明单三角面，输出到 `controller/`。
