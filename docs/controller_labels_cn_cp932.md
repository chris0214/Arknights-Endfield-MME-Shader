# 控制器中文汉字标签

## 目标

所有运行时控制器均面向中国用户。标签表达中文含义和中文语序，但只使用旧版日文
MMD、MME 和 FXC 能通过 CP932/JIS 稳定读取的汉字。它们不是日语翻译。

## 常用替代字

| 标签字符 | 中文理解 |
| --- | --- |
| `髪` | 发、头发 |
| `寛` | 宽、宽度 |
| `強` | 强、强度 |
| `辺` | 边、边缘 |
| `対` | 对、对比度 |
| `鋭` | 锐、锐利 |
| `線` | 线、法线或曲线 |
| `紅` | 红、红色通道 |
| `緑` | 绿、绿色通道 |
| `藍` | 蓝、蓝色通道 |
| `飽和` | 饱和度 |
| `範囲` | 范围 |
| `旋転` | 旋转 |

`+` 和 `-` 表示相对烘焙默认值向正、负方向调整；`++` 是五倍动态范围的第二档。
所有表情为 `0` 时，Shader 必须保持原始封版外观。

## 编码合约

控制绑定 `.inc` 文件保存为 CP932，PMX 表情名保存为 PMX 自身声明的 Unicode 编码。
构建器会比较两边的完整名称和顺序。标签不一致时构建立即失败，避免出现控制器可见但
Shader 不响应的静默错误。
