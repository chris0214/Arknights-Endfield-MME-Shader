# EndfieldFace_controller.pmx 规格

`EndfieldFace_controller.pmx` 是独立的脸部与眼部运行时控制器。它与头发和全局灯光控制器
分离。所有 morph 名均为 ASCII，所有滑块的中性值均为 `0`；不加载控制器时，画面与 Shader
烘焙默认完全一致。当前控制器包含 39 个 morph：25 个 Face morph 与 14 个 Eye morph，
并在 MMD 表情面板中拆成 `Face Controls` 与 `Eye Controls` 两组。

## SDF 边缘锐度

这一组是互斥方向控制：

| morph | 0 -> 1 的作用 |
|---|---|
| `SDF鋭度+` | Goo SDF `sharp` 从烘焙中性值 `0.5` 提高到 `5.0`，边缘更锐利 |
| `SDF鋭度-` | Goo SDF `sharp` 从烘焙中性值 `0.5` 降低到 `0.05`，边缘更柔和 |

两个表情不要同时拉高。Shader 先计算二者的有符号差值，因此相同数值会互相抵消并回到中性。
该控制只改变 Sigmoid 的斜率，不改变 SDF 角度阈值、左右镜像、中心偏移或阴影颜色。

## RD 色彩强度

RD 色差修正的烘焙中性值为 `0.4`。它只控制 `RD.rgb` 提取出的色相/色差参与量；现有
亮度补偿会继续维持输入漫反射的明度，因此不会把灰色 RD 或强色差直接乘成死黑。

| morph | 0 -> 1 的作用 |
|---|---|
| `RD色強+` | RD 色彩强度从中性值 `0.4` 提高到 `1.0` |
| `RD色強-` | RD 色彩强度从中性值 `0.4` 降低到 `0.0` |

两个表情同样不要同时拉高；相同数值会互相抵消并回到 `0.4`。控制器未加载或两项均为
`0` 时，结果严格保持当前实机确认的 `0.4`。当前控制接在
正式入口 `EndfieldFace_Final.fx`。

## Face AO 强度

AO 使用 `D.a` 作为线性遮罩，并以 `pow(D.a, strength)` 调节深浅。实机把原中性值 `0.6`
配合 `AO強-=0.5` 后确认自然，对应实际指数正好是 `0.3`，因此当前烘焙中性值改为 `0.3`。
遮罩形状和贴图本身不变。

| morph | 0 -> 1 的作用 |
|---|---|
| `AO強+` | 指数从中性值 `0.3` 提高到 `5.0`，AO 更强、更暗 |
| `AO強-` | 指数从中性值 `0.3` 降低到 `0.0`，拉满时完全关闭 AO |

两个表情同值时抵消回 `0.3`。当前主线不是把 AO 乘到最终颜色，而是按知乎/MyZmd 契约以
`min(RD.a, AO)` 限制亮/暗 Ramp 权重；AO 只把局部推向 LUT 暗色，不会压成黑块。主线入口为
`EndfieldFace_Final.fx`；旧乘法反例和逐级诊断入口已在封版清理中删除。

## 嘴唇高光

| morph | 0 -> 1 的作用 |
|---|---|
| `唇高光+/-` | 高光强度在 `0 <- 2 -> 10` 间调节 |
| `唇高光移+/-` | 视角横移量在 `0 <- 0.05 -> 0.25` 间调节 |
| `唇高光淡+/-` | 正面光渐隐宽度在 `0 <- 0.2 -> 1` 间调节 |

## Face Rim 宽度

Rim 使用 `cm_M.a` 的连续灰阶，不修改贴图和 UV。Shader 将直观宽度倍率转换为
`pow(mask, 1 / width)`；默认 `1.0x` 时保持贴图原样。

| morph | 0 -> 1 的作用 |
|---|---|
| `辺光幅+` | 宽度从 `1.0x` 增加到 `5.0x` |
| `辺光幅-` | 宽度从 `1.0x` 缩小到 `0.2x` |

两个表情同值时相互抵消。该参数只重映射 `cm_M.a`，不改变灯光左右选择、正面光门控、
`faceNoV` 侧视渐隐或 Rim 颜色。当前实机测试入口的 Rim 强度已从 `2.0` 降为 `1.0`。

## Face Rim 强度

| morph | 0 -> 1 的作用 |
|---|---|
| `辺光強+` | 强度从 `1.0` 增加到 `5.0` |
| `辺光強-` | 强度从 `1.0` 降低到 `0.0` |

两个表情同值时相互抵消并回到 `1.0`。它只缩放最终 Rim 能量，不改变 `cm_M.a` 宽度、
受光侧选择、正面光门控或 `faceNoV` 渐隐。

## Face Rim 对比度与颜色

| morph | 0 -> 1 的作用 |
|---|---|
| `辺光硬+` | 遮罩对比度从 `1` 提高到 `8`，边缘更集中、更硬 |
| `辺光硬-` | 遮罩对比度从 `1` 降低到 `0.25`，边缘更宽、更柔 |
| `辺光色切` | `0` 读取 PMX 材质 `EDGECOLOR.rgb`；`1` 使用手动 Rim RGB；中间值连续混合 |
| `RimR/G/B+/-` | 只在手动颜色分支中把对应通道推向 `1` / `0` |

PMX 描边色按 sRGB 输入并在线性光照空间参与合成。关闭 MMD 原生描边不会阻止 Shader 读取
`EDGECOLOR`。描边 Alpha 不参与 Rim 强度，强度继续由 `辺光強+/-` 独立控制。

## Eye Controls

眼部七组参数使用统一的 Range5 映射。`+` 从烘焙值放大到 `5x`，`-` 从烘焙值降低到 `0x`；
Shader 先计算 `saturate(plus) - saturate(minus)`，所以两项同值会精确抵消回中性。主虹膜与
EyeThrough 捕获共用同一控制函数，刘海内外不会出现不同参数。

| morph | 烘焙中性值 | 拉满作用 |
|---|---:|---|
| `虹膜亮度+/-` | `0.88` | 虹膜最终亮度 `0x..5x` |
| `虹膜飽和+/-` | `1.10` | 虹膜最终饱和度 `0x..5x` |
| `瞳孔視差+/-` | Depth `0.020`、Max Offset `0.035` | 视差深度与安全上限同步 `0x..5x` |
| `眼反射05+/-` | `0.5666667` | 相机空间反射强度 `0x..5x` |
| `眼反射07+/-` | `0.08` | UV 固定发光层强度 `0x..5x` |
| `眼高光+/-` | `1.4` | 独立几何高光发光强度 `0x..5x` |
| `眼白亮度+/-` | `1.0` | 眼白柔光结果的最终亮度 `0x..5x` |

这些控制都不改变纹理、UV、深度状态、EyeThrough 侧面隐藏或材质顺序。极端值用于适配不同
灯光与后期环境，不代表任何单一角色的推荐默认值。

`眼高光-` 是唯一带可见性语义的负向控制：它降低独立高光面片的覆盖率，拉满时在写入颜色和
深度之前直接裁掉像素。因此关闭 `目HL` 不会留下不可见的深度面片去遮挡眼白或虹膜；
`眼高光+` 只提高发光强度，不扩大覆盖范围。

`眼反射05+/-` 与 `眼反射07+/-` 是历史 Profile 的内部兼容名称。未来 GUI 应分别显示为
`Environment MatCap` 与 `Detail MatCap`，并根据角色 Profile 绑定 05、06、07、08 或自定义资源。
角色没有对应能力时应关闭并隐藏或禁用该组控件；控制器 PMX 可以继续保持统一的 30 morph
结构，禁用能力对应的 morph 只是无害的 no-op。

## 生成与校验

控制器从现有 `Endfield_controller.pmx` 的有效 PMX 骨架生成，源文件不会被修改：

```powershell
python tools\build_face_controller.py
```

生成器会验证 Shader `CONTROLOBJECT` 名称、PMX morph 顺序和中性 Bone Morph 结构，并输出
文件大小与 SHA-256。当前生成结果为 39 个 morph、4220 bytes，SHA-256：
`8C22FAE70E11BC80DF53D98BC1F6B79040DD1E8D677ABD24AB37804B35AF959E`。
