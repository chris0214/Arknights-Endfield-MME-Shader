# Cloth Controller Specification

## Runtime Model

`EndfieldCloth_controller.pmx` is generated by
`tools/build_cloth_controller.py`. It contains 80 neutral bone morphs grouped
into Tone, AO, Surface, Specular, Environment, Rim and Shadow display frames.

Every morph at `0` reproduces the accepted default clothing preset for the
selected model. Normal
strength controls use signed `+/-` pairs. Intensity controls map the MMD
`0..1` slider to a Shader range from off to five times the baked value.

| --- | ---: | --- |

| `辺光色切` | `0.00` | `0` PMX `EDGECOLOR.rgb`, `1` manual RGB; intermediate values blend |
| `RimR/G/B+/-` | baked Rim RGB | manual color channels, each clamped to `0..1` |
| `Screen辺光強+/-` | `0.45` | Light-side screen-space Rim intensity |
| `Screen辺光幅+/-` | `1.00` | Screen-space depth offset multiplier |

The HDR source has a fixed relative exposure of `0.65` against MatCap. This
aligns their perceived energy while `Env高光強+/-` remains the shared
artistic strength control.

Both cloth Rim paths share color mode and contrast while keeping separate
strength and width controls. Mode `0` reads PMX edge RGB, decodes it from sRGB,
and remains available after the native MMD outline is disabled. Mode `1` uses
the Shader's manual Rim base color plus `RimR/G/B+/-`. `EDGECOLOR.a` does not
change Rim intensity.

## Global Layer

The existing `Endfield_controller.pmx` is the character-wide controller. Its
`Bright/Dark` morphs control lit and shadow branches across hair, face, skin
and cloth. `Brightness` and `Saturation` apply after each material's local
lighting and therefore provide a unified final grade without replacing any
part-specific controller.

The global `+` and `++` morphs together provide up to five times the neutral
value. A corresponding `-` morph reaches zero.
